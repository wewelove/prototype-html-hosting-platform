# axhub 开发文档

## 1. 项目概述

axhub 是面向企业内网的 HTML 原型资产托管平台，把产品经理、设计师产出的 HTML 原型、AI 生成页面和 Axure 导出内容转化为可管理、可分享、可统计的团队资产。

目标用户：产品经理、设计师、产品团队。

## 2. 技术栈

- **Next.js 16 + React 19 + TypeScript**：管理端、原型访问页与服务端 API
- **Node.js 24 内置 `node:sqlite`**：单文件数据库，无需额外数据库驱动
- **lucide-react**：图标库
- **puppeteer-core + Chromium**：生成原型首页 WebP 截图
- **jszip / node-unrar-js**：ZIP / RAR 解压
- **bcryptjs / jose**：密码哈希与 JWT 会话
- **Vitest**：单元测试运行器

## 4. 架构概览

```
用户浏览器
  │
  └── Next.js（页面 + API Routes）
        ├── 认证：JWT 会话 Cookie（jose）
        ├── 原型 CRUD / 上传 / 下载
        ├── 分享与访问密码
        └── SQLite（node:sqlite，单文件）
              └── 数据目录 /data：数据库 / 原型文件 / 资源 / 截图
```

### 数据模型

- **用户**：账号（唯一、忽略大小写）、密码哈希、姓名、部门、角色（user/admin/super_admin）、状态、存储配额
- **部门 / 管理员范围**：部门树 + `admin_department_scopes` 维护管理员管辖范围
- **原型**：公共码、分享码、名称、负责人、部门、分组、分类、HTML 路径、文件大小、公开 / 分享配置、访问量
- **日志**：`project_visits`（PV/UV）、`login_logs`、`platform_events`、`share_password_attempts`

## 5. 核心模块

| 模块 | 说明 |
| --- | --- |
| `src/lib/db.ts` | SQLite 客户端：单连接复用、WAL、事务串行化、编号占位符 |
| `src/lib/auth.ts` | 读取当前用户、角色守卫（requireUser / requireAdmin / requireSuperAdmin） |
| `src/lib/access-policy.ts` | 按路由类型（public / share）决策访问权限 |
| `src/lib/department-scope.ts` | 按角色计算可访问部门集合 |
| `src/lib/prototype-upload.ts` | 解析 HTML / ZIP / RAR / 文件夹，校验入口与路径安全 |
| `src/lib/file-storage.ts` | 原型文件读写与删除，路径越界防护 |
| `src/lib/capture-preview.ts` | 启动临时 HTTP 服务 + Puppeteer 截图，队列串行执行 |
| `src/lib/storage-budget.ts` | 个人配额与平台磁盘安全阈值校验 |
| `src/lib/share-session.ts` | 分享访问授权 JWT 与 Cookie |
| `src/lib/session.ts` | 登录会话 JWT 与 Cookie 选项 |

## 6. 开发流程

```bash
npm ci
cp .env.example .env     # 配置 DATABASE_FILE、密钥等
npm run migrate          # 初始化 / 更新数据库结构
npm run bootstrap        # 创建首位超级管理员（已有用户则跳过）
npm run dev              # 启动开发服务器
```

访问 `http://localhost:3000/manage/login`。

### 提交前检查

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## 7. 环境变量

| 变量 | 说明 | 默认 / 示例 |
| --- | --- | --- |
| `DATA_DIR` | 数据目录 | `/data` |
| `DATABASE_FILE` | SQLite 数据库文件路径 | `/data/axhub.sqlite3` |
| `NEXT_PUBLIC_BASE_PATH` | 应用基路径，**构建期**内联，需用 `--build-arg` 指定 | `/manage` |
| `NEXT_PUBLIC_BASE_URL` | 对外访问地址，用于分享 / 查看链接，**运行期**读取 | `http://localhost:3000` |
| `APP_HOST_PORT` | 宿主机映射端口 | `3000` |
| `SESSION_SIGNING_SECRET` | 会话签名密钥（≥32 字符） | 必填 |
| `SHARE_PASSWORD_ENCRYPTION_KEY` | 分享密码加密密钥（≥32 字符，与会话密钥不同） | 必填 |
| `COOKIE_SECURE` | 会话 Cookie 是否强制 Secure | `false`（内网 HTTP） |
| `CHROMIUM_EXECUTABLE_PATH` | Chromium 路径 | `/usr/bin/chromium` |
| `STORAGE_RESERVE_RATIO` | 预留磁盘比例 | `0.2` |
| `BOOTSTRAP_SUPER_ADMIN_*` | 首位超级管理员信息 | 见 `.env.example` |

## 8. 注意事项

1. **basePath 是构建期常量**：`NEXT_PUBLIC_BASE_PATH` 会被静态内联进代码，构建后运行期修改无效，必须通过构建参数确定；`NEXT_PUBLIC_BASE_URL` 则是运行期读取（不要把它加到构建参数，否则会被内联而失去运行期可配置性）。
2. **SQLite 并发**：单写通道，事务期间其它请求排队（`db.ts` 中串行化）。
3. **截图依赖 Chromium**：容器镜像已内置，本地开发需系统安装 Chrome / Edge / Chromium。
4. **RAR 解压**：依赖 `node-unrar-js` 的 WASM 模块，首次加载略有延迟。

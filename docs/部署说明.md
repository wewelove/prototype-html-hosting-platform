# 部署说明

## 部署目标

为“原型托管平台”创建一套完全独立的部署环境，包括新数据库、新 Docker Compose 项目、新数据卷。

## 环境要求

- Ubuntu 22.04 或更高版本
- Docker Engine 与 Docker Compose Plugin
- 最少 2 核 CPU、4GB 内存；磁盘大小按原型文件规模评估

## 配置步骤

1. 将代码放入服务器独立目录。
2. 参考 `.env.example` 创建服务器本地 `.env`。
3. 为以下字段生成互不相同的新值：
   - `SESSION_SIGNING_SECRET`（至少 32 字符）
   - `SHARE_PASSWORD_ENCRYPTION_KEY`（至少 32 字符，与会话密钥不同）
   - `BOOTSTRAP_SUPER_ADMIN_PASSWORD`（至少 8 字符）
4. 根据需要调整其他配置（如 `NEXT_PUBLIC_BASE_PATH`、`APP_HOST_PORT` 等）。
5. **构建镜像**：

```bash
docker build -t axhub:latest .
# docker build --build-arg NEXT_PUBLIC_BASE_PATH=/manage -t axhub:latest .
```

6. **启动服务**：

```bash
docker compose up -d
```

7. 检查健康状态：

```bash
docker compose ps
curl --fail http://localhost:3000/manage/api/health
```

## 数据边界

- 首次启动只执行 `database/migrations`，不得导入旧生产数据库。
- SQLite 数据库文件、上传目录和预览图都位于 `axhub` 数据卷，由本项目 Compose 创建。
- `.env` 不提交到 Git，不复制到日志或文档。

## 局域网部署说明

- 本部署方案不包含 HTTPS，适用于局域网环境。
- 直接通过 HTTP 访问应用端口（默认 3000）。
- 如需公网访问，请在前端自行配置反向代理（如 Nginx、Caddy、Traefik）并启用 HTTPS。
